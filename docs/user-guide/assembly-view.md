# Assembly View & Highlighting

The assembly output viewer provides clear visualization of machine instructions and intermediate bytecode.

## Highlighting Modes

Toggle the highlighting mode via the **Highlight** button in the top toolbar:

1. **Highlight: Off**: Standard syntax highlighting without cross-selection coloring.
2. **Highlight: All**: Colors each source block and its corresponding assembly instructions with matching hue groups.
3. **Highlight: Selection**: Highlights the exact assembly instructions generated by the source line currently under the editor cursor.

## Syntax Highlighting

The viewer provides assembly syntax highlighting for instructions, registers, numerical operands, directives, and labels.
