# Assembly View

The compiler pane's editor shows the selected artifact. For assembly it adds source mapping, highlighting
and opcode help.

## Source ↔ assembly mapping

When the compiler emits debug line information (`.loc` directives; OCTOS adds `-g` unless you choose a debug
level), OCTOS builds a map *source line → assembly lines*. It is used by the highlighting modes below and
by the analysis panel's *Source lines* column. If a mapping cannot be resolved it is simply absent — OCTOS
does not guess.

## Highlighting modes

The **Highlight** button on the source toolbar cycles through three modes:

1. **Highlight: Off** — normal syntax colours only.
2. **Highlight: All** — every source line gets a hue; its assembly instructions get the same tint.
3. **Highlight: Selection** — only the instructions generated by the source line under your cursor are
   highlighted; they follow the cursor.

The tints are translucent so they stay readable on light and dark themes.

## Syntax highlighting

Assembly: instructions (bold), registers, numbers, labels, comments. Other artifact types have their own
rules ([Artifacts](artifacts.md)): LLVM IR, JVM bytecode, CPython bytecode, CIL. x86 rules are never applied
to bytecode.

## Opcode tooltips

Hover a **mnemonic** to see a summary, the flags it affects and syntax examples. OCTOS has separate databases
for x86-64 and ARM64, so `retq` is known on x86 but not on ARM, and `ldp` on ARM but not on x86. Only the
mnemonic token triggers a tooltip — not operands, labels, directives or comments.

## What the view hides

By default OCTOS removes noise (CFI directives, compiler labels, segment directives …). Everything is
configurable: [Filters](filters.md). The *raw* listing is kept for the analysis panel and the diff, which
therefore see the full text even if your view is filtered.

## Line numbers in the analysis

Function and block line numbers in the [analysis panel](analysis.md) refer to the raw listing. Jumping to
such a line works only if the line survived your filters; otherwise the status bar tells you it is hidden.
