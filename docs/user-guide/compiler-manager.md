# Compiler Manager

The **Docker Compiler Manager** dialog allows you to discover, download, and manage compiler toolchain images directly from Docker Hub.

Access it via **Tools > Docker Compiler Manager...** from the main menu.

## Features

- **Category Browsing**: Select between C++, C, Clang, Rust, Java, Python, and C#.
- **Docker Hub Tag Discovery**: Fetches stable releases and versions directly from official Docker Hub registries.
- **Pull Progress Tracking**: Real-time download progress bar and percentage indicator.
- **Local Cache Management**: View installed image sizes and remove unused toolchain images to free disk space.
- **Architecture Validation**: Matches image architectures to your host system (`amd64`, `arm64v8`, `arm32v7`).
