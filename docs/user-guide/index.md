# User Guide

The OCTOS interface is designed to make comparing compiler outputs straightforward.

## Interface Overview

- **Source Code Editor**: On the left pane. Write your code here.
- **Compiler Output Panes**: On the right pane. Add multiple panes using the **+ Compare** button to analyze different compilers side-by-side.
- **Top Bar**: Controls for changing themes, inserting snippets, and managing compilation panes.

## Filters

Assembly output can be customized by toggling various filters from the **Filters** menu:
- Hide/Show Segment Directives
- Hide/Show Data Directives
- Demangle Identifiers
- Hide/Show Metadata and Debug Information

## Managing Compilers

Open the **Tools -> Docker Compiler Manager** to pull new containerized toolchains and manage existing ones.
