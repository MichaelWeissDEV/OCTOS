# OCTOS Roadmap

This document outlines the planned future work for OCTOS.

## UI/UX
- Enhance syntax highlighting for various assembly flavors
- Improve compiler output pane resizing and layout logic
- Provide clearer status indicators for background Docker pulls

## Compiler Support
- **Ada**: Implement full assembly extraction backend (currently incomplete)
- Investigate support for Go and Swift

## Assembly Analysis
- Introduce assembly diff comparison views
- Add architectural-specific metadata and documentation links in assembly view

## Platform Support
- Improve and test native macOS support (currently limited)
- Provide official Windows support guidelines without WSL2 requirement

## Packaging & Testing
- Establish automated CI/CD pipeline for tests and builds
- Distribute pre-built binaries and AppImages for Linux
